## Konačni flow
`5.1 Cilj sata → 5.2 Prijedlog strukture i sadržaja → 5.3 Plan sata → 5.6 Potvrđena priprema / Sat je spreman → 6.1 PLUS 5 Ploča`

Pomoćne grane:
- `5.3 → 5.4 Odabir aktivnosti / Knowledge Blocka → 5.3`
- `5.3 → 5.5 Detalj / uređivanje aktivnosti → 5.3`
- materijal → 4.2
- novi materijal → 4.3
- uvoz → 4.4

## Ključna granica
Modul 5 opisuje **što planiramo**. Potvrđeni rezultat je `Lesson Plan`.

`Lesson Plan` ne stvara Attempt, Evidence Event niti mijenja Knowledge Model.

`Pokreni sat` na 5.6 stvara `Lesson Session`; tek modul 6 bilježi stvarno izvedeno.
