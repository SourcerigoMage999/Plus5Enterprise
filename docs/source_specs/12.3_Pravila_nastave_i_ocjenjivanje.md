# 12.3 Pravila nastave i ocjenjivanje

## Source
`Popis svih ekrana koje vidi učitelj.docx`.

Izvor opisuje skalu ocjenjivanja, vidljivost procjena, uključivanje procjene razine znanja, način procjene (ručno/sustav/kombinirano/AI+kombinirano), razine i njihove raspone.

Sustav može dati procjenu, ali učitelj pregledava i potvrđuje/korigira tamo gdje je tako definirano.

Ostala pravila uključuju otkazivanje/nedolazak, kašnjenje i domaće zadaće.
