# 12.5 Postavke obavijesti

## Source
`Popis svih ekrana koje vidi učitelj.docx`.

Postavke određuju želi li učitelj biti obaviješten o pojedinom poslovnom događaju i kojim kanalom, ali ne mijenjaju samu poslovnu funkcionalnost izvornog modula.

Primjer: postavka za obavijest o prijedlogu grupe nije isto što i uključivanje samih prijedloga grupa.
