# 9.2 Razgovor

## Source
`Popis svih ekrana koje vidi učitelj.docx`.

Puni thread/composer s participantima, porukama, bodyjem, privicima, read stateom i Context Linkovima.

Može se otvoriti iz učenika, domaće, termina, izvještaja ili obavijesti s već prenesenim kontekstom/primateljem.

AI pomoć: `Predloži odgovor → učitelj pregledava/uređuje → Pošalji`. Nikada AI → roditelj automatski.
