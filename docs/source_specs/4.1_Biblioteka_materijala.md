# 4.1 Biblioteka materijala

## Source
`Popis svih ekrana koje vidi učitelj.docx` — updated source snapshot 2026-09-01.

## Svrha
Centralna biblioteka nastavnih materijala.

## Glavni prikazi
- Moji materijali
- Dijeljeni sa mnom
- grid/kartice ili lista
- sortiranje
- pretraživanje i strukturirani filteri

## Filteri
- Predmet
- Program
- Razred
- Vrsta materijala
- Oznake
- samo moji materijali
- poništavanje svih filtera

## Materijal
Klik na preview ili naziv otvara `4.2 Pregled materijala`.

Akcije preko `•••`:
- Otvori
- Uredi
- Dupliciraj
- Dodaj u pripremu sata
- Podijeli
- Arhiviraj
- Obriši

## Dodavanje u pripremu
Odabir postojeće pripreme/sata → potvrda → materijal se povezuje s pripremom bez napuštanja 4.1.

## Dijeljenje
Odabir učitelja/korisnika → Podijeli. Točan permission model ostaje predmet tehničkog/business contracta odgovarajuće faze.

## Vrste materijala
Prezentacije, radni listovi, kartice za razgovor, interaktivne vježbe, video, audio, kvizovi, slike, plakati, mape i druge definirane vrste služe kao filteri.

## Kontekst pripreme sata
Ako je biblioteka otvorena iz `5.1`, može prikazati preporučene materijale; `Dodaj u sat` vraća u aktivnu pripremu.

## Navigacija
- `+ Novi materijal` → 4.3
- materijal → 4.2
- iz aktivne pripreme → povratak na 5.1
