# 11.2 Sati i naplata

## Source
`Popis svih ekrana koje vidi učitelj.docx`.

Održan Lesson Session automatski stvara financijsku stavku; početni status je `ZA NAPLATU` osim ako je uplata odmah evidentirana.

Učitelj može promijeniti status, pojedinačni iznos, napomenu ili poništiti stavku uz audit. Promjena iznosa pojedine stavke ne mijenja standardni cjenik.

Grupni sat može imati ukupnu vrijednost i zasebni status naplate po učeniku.

Podsjetnik roditelju se samo priprema; teacher potvrđuje slanje kroz 9.2.
