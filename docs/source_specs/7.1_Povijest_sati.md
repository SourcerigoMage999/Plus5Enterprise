# 7.1 Povijest sati

## Source
`Popis svih ekrana koje vidi učitelj.docx`.

Kronološki i pretraživ indeks završenih Lesson Sessiona, globalno ili filtrirano na učenika/grupu.

Prikazuje datum, vrijeme, naziv, učenika/grupu, program, dominantnu temu, trajanje, status cilja i točnost u aktivnostima.

`Točnost` nije isto što i `znanje/mastery`.

Filteri mogu uključiti razdoblje, učenika/grupu, tip sata, program, temu/KC, status cilja, materijal, poteškoću, domaću i follow-up.

Pogrešno evidentiran sat se invalidira/voida uz audit; ne briše se povijesno.
