# 9.1 Poruke / Inbox

## Source
`Popis svih ekrana koje vidi učitelj.docx`.

Dvostruki prikaz: lista razgovora + preview odabranog razgovora.

Tabovi: Inbox, Poslano, Arhivirano, Nacrti.

Conversation može imati Context Link prema učeniku, domaćoj, terminu, održanom satu, izvještaju ili materijalu.

Badge broji razgovore s nepročitanim porukama, ne ukupan broj Messagea.

Grupna poruka roditeljima je broadcast; odgovori roditelja stvaraju privatne Conversatione s učiteljem, ne zajednički roditeljski chat.
