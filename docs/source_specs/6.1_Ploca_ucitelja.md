# 6.1 PLUS 5 Ploča učitelja

## Source
`Popis svih ekrana koje vidi učitelj.docx`.

Glavni operativni ekran Lesson Sessiona. Layout:
- lijevo: Lesson Timeline
- sredina: aktivni rad / 6.2
- desno: live učenici
- gore: vrijeme, Student View, Sažetak, Završi sat

Planirane aktivnosti imaju statuse Čeka/U tijeku/Pauzirano/Završeno/Djelomično/Preskočeno.

Učitelj može dodati ad-hoc aktivnost/Knowledge Block/Quick Check bez izmjene originalnog Lesson Plana.

AI samo preporučuje intervenciju; učitelj odlučuje.

Autosave bilježi stvarne runtime događaje. Povratak nakon prekida mora prepoznati aktivni Lesson Session.
