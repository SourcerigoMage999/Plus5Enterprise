# 8.3 Detalj domaće zadaće

## Source
`Popis svih ekrana koje vidi učitelj.docx`.

Prikazuje Assignment i Submissione učenika, statuse predaje/pregleda, rezultate/Attempts, Evidence gdje je primjenjivo, izvorni Lesson Session i komunikacijske akcije.

Task izmjena nakon prvog učenikovog rada stvara novu Task Version.

Assignment se može zatvoriti (`CLOSED`) ili otkazati (`CANCELLED`) bez brisanja postojećih Submissiona/Attempts/Evidencea.

Podsjetnik se šalje samo relevantnim učenicima/roditeljima nakon teacher previewa/potvrde.
